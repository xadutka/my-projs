# ARSENTIY — персональное портфолио разработчика

Одностраничный сайт-портфолио в стиле Premium Dark / Editorial Tech. React + TypeScript + Vite + Tailwind CSS, иконки Lucide. Без backend, без сторонних API, без трекинга и внешних запросов при просмотре.

Все личные данные вынесены в типизированные файлы `src/data/`. Пока сведения не заполнены, сайт не показывает выдуманного: пустые контакты, навыки и документы скрыты или заменены нейтральными сообщениями.

## Требования

- Node.js 20.19 или новее (подойдёт 22 LTS)
- npm 10 или новее

## Важно: состояние проекта в этом архиве

Архив собран в среде, где `npm install` не работал (registry.npmjs.org отвечал 403). Поэтому:

- папка `node_modules` в архив **не входит**, зависимости **не установлены**: React, React DOM, Vite, `@vitejs/plugin-react`, Tailwind CSS (`tailwindcss`, `@tailwindcss/vite`), Lucide (`lucide-react`), TypeScript и типы;
- все они перечислены в `package.json` и установятся командой `npm install` на вашем компьютере;
- `npm run dev` и `npm run build` (то есть сам Vite) в той среде **не запускались**. Код проверялся отдельно: типы с заглушками, сборка esbuild и прогон в Chromium. Если на вашей машине сборка выдаст ошибку, пришлите её текст.

## Запуск на Windows

1. Установите Node.js LTS (20.19 или новее, лучше 22) с https://nodejs.org. Проверьте в терминале: `node -v` и `npm -v`.
2. Распакуйте ZIP (правый клик → «Извлечь всё»), откройте папку `arsentiy-portfolio`.
3. Откройте в ней PowerShell или командную строку (в Проводнике: клик по адресной строке, набрать `cmd`, Enter).
4. Выполните:

```bat
npm install
npm run dev
```

Сайт откроется на `http://localhost:5173`. Остановка: `Ctrl+C`.

Для production-сборки: `npm run build` (результат в папке `dist/`), затем `npm run preview`.

Быстрый запуск двойным кликом: `start-dev.bat` (установит зависимости при первом запуске и запустит сайт) и `build.bat` (соберёт сайт).

Если PowerShell пишет, что выполнение скриптов отключено, используйте командную строку (`cmd`) либо выполните один раз `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.

### Образование

В `src/data/education.ts` в закомментированных полях `organization`, `years`, `specialty` можно указать проверенные сведения: они появятся на карточке автоматически. Не добавляйте то, что не можете подтвердить.

### Дипломы и сертификаты

1. Закройте на скане номера документов, подписи, даты рождения, адреса и другие личные данные.
2. Положите изображение в `public/certificates/`, например `diploma-1.jpg`.
3. Добавьте запись в `src/data/certificates.ts`:

   ```ts
   {
     id: 'diploma-1',
     title: 'Название документа',
     image: '/certificates/diploma-1.jpg',
     alt: 'Скан диплома «Название документа»',
     issuer: 'Организация, выдавшая документ',
     year: '2024',
     description: 'Что подтверждает документ.',
   }
   ```

Пока список пуст (или файлы не найдены), секция скрыта; в режиме разработки вместо неё показывается подсказка. Просмотр увеличенного изображения закрывается кнопкой, клавишей Escape и кликом вне окна.

> В `.gitignore` папки `public/certificates/` и `public/resume/` исключены из репозитория, чтобы личные документы не попали в открытый доступ случайно. Если вы публикуете сайт через Git (Vercel, Netlify, GitHub Pages) и хотите включить файлы в деплой, удалите соответствующие строки из `.gitignore` осознанно или собирайте сайт локально и загружайте папку `dist/`.

### Проекты

Три стартовые записи в `src/data/projects.ts` — концепции, их превью нарисованы встроенными SVG-макетами. Чтобы заменить их настоящими проектами:

1. Измените `status` на `'in-progress'` или `'completed'`.
2. Заполните `stack` только теми технологиями, которые реально использованы.
3. Добавьте `repoUrl` и `demoUrl`, если они есть.
4. Положите скриншоты в `public/projects/` и перечислите в `screenshots` (`{ src: '/projects/shot-1.png', alt: 'Описание' }`).
5. Удалите `disclaimer` и `preview`, если используете скриншоты.

Новый проект — это ещё один объект в массиве; сетка и модальное окно подстроятся сами.

### Навыки

Заполните массив в `src/data/skills.ts`:

```ts
{ name: 'Python', category: 'languages', usage: 'Скрипты автоматизации', projects: ['Название проекта'] }
```

Категории: `languages`, `frontend`, `backend`, `databases`, `tools`, `automation`, `ai`. Пока массив пуст, показывается сообщение «Список технологий постепенно пополняется по мере работы над проектами».

### Контакты

В `src/data/socials.ts` заполните `value` и `url` нужных контактов:

```ts
{ kind: 'email', label: 'Email', value: 'name@example.com', url: '' }
{ kind: 'telegram', label: 'Telegram', value: '@username', url: 'https://t.me/username' }
{ kind: 'github', label: 'GitHub', value: 'username', url: 'https://github.com/username' }
```

Пустые контакты не отображаются нигде на сайте, в том числе в подвале. Для email автоматически появляются кнопки «Написать письмо» (`mailto:`) и «Скопировать email».

### PDF-резюме

Положите файл в `public/resume/` (например, `arsentiy-cv.pdf`) и раскомментируйте `resumeUrl: '/resume/arsentiy-cv.pdf'` в `src/data/profile.ts`. В блоке контактов появится кнопка «Резюме (PDF)».

### Портрет

Положите фото в `public/` и раскомментируйте поле `portrait` в `src/data/profile.ts`. Оно заменит абстрактную композицию на первом экране.

## Публикация

Сборка:

```bash
npm run build
```

Готовый сайт — папка `dist/`. Это обычная статика, её можно разместить на любом хостинге:

- **Vercel / Netlify / Cloudflare Pages:** подключите репозиторий, команда сборки `npm run build`, папка публикации `dist`.
- **GitHub Pages:** загрузите содержимое `dist/` в ветку публикации. Если сайт будет в подпапке (`username.github.io/repo`), добавьте в `vite.config.ts` параметр `base: '/repo/'`.
- **Свой сервер:** скопируйте `dist/` в корень сайта (nginx, Apache и т. д.).

После публикации укажите настоящий домен в `src/data/seo.ts` (`siteUrl: 'https://ваш-домен'`) и пересоберите сайт: появятся канонический URL, `og:url` и абсолютная ссылка на превью. Без домена превью в соцсетях может не отображаться.

## Что проверить перед публикацией

- [ ] Заполнены только те контакты, которыми вы готовы делиться; ссылки открываются
- [ ] В `education.ts` нет непроверенных данных
- [ ] Навыки в `skills.ts` — только те, которыми вы действительно владеете
- [ ] Проекты-концепции помечены как концепции; у настоящих работ указаны реальные ссылки
- [ ] Сканы документов очищены от личных данных
- [ ] Указан домен в `seo.ts`, проверено превью в соцсетях
- [ ] `npm run build` проходит без ошибок, `npm run preview` открывается без ошибок в консоли
- [ ] Сайт просмотрен на телефоне и на компьютере, нет горизонтальной прокрутки
- [ ] В репозитории нет токенов, ключей и личных документов

## Доступность и производительность

- Семантическая разметка, состояния фокуса, пропуск навигации («Перейти к содержимому»)
- Клавиатурная навигация, доступное мобильное меню и модальные окна (Escape, фокус удерживается внутри окна)
- Поддержка `prefers-reduced-motion`; на телефонах отключены тяжёлые декоративные анимации
- Системные шрифты, без внешних запросов; внешние ссылки открываются с `rel="noopener noreferrer"`
